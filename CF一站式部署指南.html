📺抖音视频代理 — 一站式部署指南

这篇文章告诉你：为什么看不了抖音视频 + 怎么解决 + 完整操作步骤（带图）

🔍 为什么抖音视频播不了？

你在看板里贴了抖音分享链接，点击播放显示 ❌。根本原因是两层限制：

🔗 抖音链接
有防盗链/CORS
→
🖥️ 浏览器直接播放
被拦截 ❌

需要一个"中间人"帮你去抖音拿视频，再传给浏览器：

📺 浏览器
你的看板
→ 请求 →
☁️ 代理服务器
CF Worker
→ 抓取 →
🎵 抖音
视频源
→
✅ 正常播放

之前的方案用 Vercel 做"中间人"，但 Vercel 免费版有 4MB 限制，抖音视频基本都超了。

现在换 Cloudflare Workers：免费、不限大小、全球加速。

🗺️ 总体流程（4 步，3 分钟）

1 复制代码 — 点一下按钮，代码就进剪贴板了
2 打开 Cloudflare — 你已登录，点链接直达创建页面
3 粘贴 + 部署 — Ctrl+V 粘贴代码 → 点右上角「部署」
4 配置看板 — 复制得到的 URL → 在看板 ⚙️ 里粘贴 → 完成 ✅

1 复制代理代码

点击下方按钮，代码会自动复制到剪贴板（90行，不需要你手动全选）。

JavaScript

2 打开 Cloudflare 创建 Worker

你已经在浏览器里登录了 Cloudflare。
现在点下面这个链接，会直接打开创建 Worker 的页面：

👉 https://dash.cloudflare.com/workers-and-pages/create/worker
💡 如果上面链接打不开，手动操作：
左侧菜单 → 「Workers 和 Pages」→ 右上角蓝色按钮「创建应用程序」→ 选择「创建 Worker」

点完后你会看到下面这样的代码编辑器界面：

🖥️
Cloudflare Worker 编辑器
屏幕中央是一个代码编辑器，里面有几行默认代码
← 「部署」按钮
↑ 代码编辑区（全选删除，粘贴新代码）
  • 全选编辑器里的默认代码（Ctrl+A）
  • 粘贴（Ctrl+V）上一步复制的代码
  • 代码替换完成后，点右上角蓝色「部署」按钮

3 部署后你会得到一个 URL

部署成功后，页面会跳转。你会看到类似这样的地址：

https://douyin-proxy.xxxxx.workers.dev （xxxxx 是你的 Cloudflare 子域名，每个人不一样）

把这个 URL 完整复制下来（包括 https://），下一步要用。

4 配置到看板

最后一步，告诉看板你的代理地址：

  1. 打开看板 👉 mmapp-two.vercel.app
  2. 左侧点 🎬 视频
  3. 顶部点 ⚙️ 齿轮图标
  4. 在输入框里 粘贴 刚才复制的 Worker URL
  5. 点 💾 保存
  6. 视频库头部出现 ☁️ CF 就说明配置成功了！
⚙️
CF Worker 配置弹窗
https://douyin-proxy.xxxxx.workers.dev
↑ 把你第3步复制的URL粘贴到这里

✅ 配置完成后

再回到 🎬 视频库，导入抖音链接，点击卡片播放：

  • 播放器左上角显示 ☁️ CF代理（不限大小）
  • 任意大小的抖音视频都能播 🎉

❓ 怎么检查是否配置成功？

看视频库页面的标题栏：

⚙️未配CF 还没配置，抖音长视频无法播放
☁️ CF 配置成功，所有抖音视频都能播

📋 总结
复制代码 → 打开 CF → 粘贴部署 → 复制 URL → 在看板 ⚙️ 配置
